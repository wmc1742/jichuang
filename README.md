## 目标

把即创从单一商业视频生成工具升级为类似 Codex 的通用创作 Agent，持续验证：

1. 首页的任务发起和素材选择。
2. 会话中的 Agent 思考、流式回复与阶段产物。
3. 图片、视频、需求分析、创意脚本、分镜、预览和成片等内容详情。
4. 可替换、可组合、可持续迭代的组件体系。
